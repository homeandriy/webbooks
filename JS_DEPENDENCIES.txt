Bootstrap 5.3.8 — npm/Vite, CSS і Modal/Collapse/Dropdown/Tab/Offcanvas,
Popper 2.11.8. Bootstrap 3 повністю прибраний із робочих стилів та розмітки:
нова flex-сітка, cards, display utilities, form-select, data-bs-атрибути.

Резервні локальні Bootstrap 5 CSS/JS синхронізуються з npm під час build:local
і підключаються лише за відсутності manifest. Roller/Fancybox/Slick видалені.
Галерея завантажується лише для записів. Спільний CSS Vite imports підключається
рекурсивно. Усі пакети входять у готову збірку теми, окремий WP-плагін не потрібен.
Тема не підключає jQuery: AJAX-клієнт використовує Fetch API, а пошук і
завантаження реалізовані через DOM API. WordPress-плагіни можуть самостійно
підключати jQuery для власних віджетів — це не залежність теми.
https://swiperjs.com/swiper-api
https://getbootstrap.com/docs/5.3/getting-started/javascript/
