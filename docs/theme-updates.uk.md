# Оновлення теми Webbooks

## Єдина папка теми

Тема має існувати лише в `wp-content/themes/webbooks/`. Релізний ZIP містить одну кореневу папку `webbooks/`; саме за назвою папки WordPress розпізнає оновлення вже встановленої теми.

## Підготовка релізу

1. Додайте опис наступної версії до `CHANGES.md` і `README.txt`.
2. Запустіть `npm run theme`.
3. Завантажте `webbooks-theme-release.zip`.

Скрипт підвищує patch-версію, збирає CSS і JavaScript, а перед завершенням перевіряє Vite manifest, CSS/JS, збіг версії та єдину папку `webbooks/` усередині архіву.

## Завантаження в WordPress

Перед оновленням зробіть резервну копію файлів і бази даних. У «Зовнішній вигляд → Теми → Додати нову → Завантажити тему» виберіть релізний ZIP. Оскільки в ньому та сама папка `webbooks/`, WordPress запропонує замінити наявну тему замість встановлення другої.

Тема `webbooks-theme-release`, яка залишилася від старого способу пакування, не є цільовою. Її можна видалити лише після перевірки активної теми `webbooks` і резервного копіювання.

## Оновлення через GitHub у wp-admin

Окремий плагін [Webbooks Git Updates](../plugins/webbooks-git-updates/README.md) додає меню **Webbooks Git → Налаштування / Статистика**, перевіряє версію у гілці `main` двічі на добу й показує кнопку встановлення готового релізу.

Плагін встановлюється окремо від теми, тому заміна теми не видаляє його. Його ZIP — `webbooks-git-updates.zip`; це інший архів, ніж `webbooks-theme-release.zip`.

Для кожного оновлення потрібен публічний GitHub Release із тегом `vX.Y.Z` і вкладеним `webbooks-theme-release.zip`. Workflow `.github/workflows/theme-release.yml` збирає й публікує його після push тега, коли workflow вже є в GitHub. Версії у гілці й ZIP мають збігатися. Сам commit без підвищення версії не є оновленням; сама нова версія без зібраного ZIP дає повідомлення очікування.

Плагін не запускає встановлення автоматично. Перед натисканням «Встановити оновлення» зробіть резервну копію: WordPress замінить локальні файли теми.

Перевірка плагіна в ізольованому Docker WordPress:
```bash
docker compose -p codex-webbooks-tests -f tests/compose.yml run --rm --no-deps --entrypoint php tests /theme/tests/git-updates.php
```
