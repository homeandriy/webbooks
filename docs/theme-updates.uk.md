# Оновлення теми Webbooks

## Єдина папка теми

Тема має існувати лише в `wp-content/themes/webbooks/`. Релізний ZIP містить одну кореневу папку `webbooks/`; саме за назвою папки WordPress розпізнає оновлення вже встановленої теми.

## Підготовка релізу

1. Додайте опис наступної версії до `CHANGES.md` і `README.txt`.
2. Запустіть `npm run theme`.
3. Завантажте `webbooks-theme-release.zip`.

Скрипт підвищує patch-версію, збирає CSS і JavaScript, а перед завершенням перевіряє Vite manifest, CSS/JS, збіг версії та єдину папку `webbooks/` усередині архіву.

## Завантаження в WordPress

Перед оновленням зробіть резервну копію файлів і бази даних. У «Зовнішній вигляд → Теми → Додати нову → Завантажити тему» виберіть релізний ZIP. Оскільки в ньому та сама папка `webbooks/`, WordPress запропонує замінити наявну тему замість встановлення другої.

Тема `webbooks-theme-release`, яка залишилася від старого способу пакування, не є цільовою. Її можна видалити лише після перевірки активної теми `webbooks` і резервного копіювання.
